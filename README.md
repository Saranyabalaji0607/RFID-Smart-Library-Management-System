# RFID-Based Smart Library Management System

## Project Overview
The RFID-Based Smart Library Management System is a simple web application designed to manage library books, book issuing, and book returns.

This project helps reduce manual work and makes library management easier.

## Features
- Add new books to the library
- Store book details and RFID Tag IDs
- Search books by name or RFID ID
- Issue books to students
- Record return dates
- Return issued books
- View total, available, and issued books

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Open the project repository.
2. Download the `index.html` file.
3. Open the file in a web browser.
4. Add books using their details and RFID IDs.
5. Use the issue and return sections to manage books.

## Note
This is a web-based demonstration project. RFID IDs are entered manually. Physical RFID hardware integration is not included.
